# 📊 Sales Performance Analyzer

A Python and NumPy based project for analyzing monthly sales performance and generating business insights.

## 🚀 Features

- Calculate Total Sales
- Calculate Average Sales
- Find Highest and Lowest Sales
- Identify Best and Worst Performing Months
- Display Above Average Months
- Quarterly Sales Analysis (Q1, Q2, Q3, Q4)
- Growth Percentage Calculation
- Business Trend Detection
- Top 3 Performing Months

## 🛠 Technologies Used

- Python
- NumPy

```bash
pip install -r requirements.txt
python main.py
```
